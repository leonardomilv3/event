# Eventing

Plataforma para descobrir, criar e participar de eventos locais.
Interface "Living City" — dark mode editorial com identidade noturna e vibrante.

## Início rápido

```bash
cd app
npm install
npm run dev
```

Acesse **http://localhost:5173**.

## Páginas

| Rota | Descrição |
|---|---|
| `/` | Landing Page |
| `/dashboard` | Dashboard do organizador |
| `/events` | Gestão de eventos |
| `/events/:id` | Detalhe de um evento |
